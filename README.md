# aw-manual

**Fast manual activity tracking for [ActivityWatch](https://activitywatch.net).**

ActivityWatch records automatically *what* happens on your computer. aw-manual
adds the human part: *what you are actually working on* (client, project,
task). You switch activities in a second, with a popover, the tray, global
hotkeys (including mouse buttons), or the command line, and aw-manual writes
the entries into its own ActivityWatch bucket.

aw-manual only records. Analysis, reports, and reconciliation with other
watchers happen downstream (AW queries, plugins, exports). It never pauses,
trims, or corrects activities on its own, for example based on AFK data.

## Features

- **Popover** (global hotkey, tray, or `aw-manual popover`)
  - fuzzy search across all favorites and their path (`acm web dev` → *ACME › Website › Development*)
  - fully keyboard-operable, with the whole favorites tree in the configured order
  - optional note per activity; a new note while running starts a new entry
  - **retroactive entries**: `-30m`, `10:00-11:15`, `since 9:30`, `10:00 +45m`, `yesterday 16:00-17:30`
  - **scroll mode**: operate it with the hotkey and the scroll wheel only (a mouse side button plus the wheel is enough); confirm with the hotkey or by dwell time
- **Tray / menu bar icon**: idle, active (tinted in the favorite's color), and offline states; configurable text next to the icon (`1h 23m`, `since 09:30`, the title, or a template); a menu with Stop, Resume, and Favorites
- **Global hotkeys**: key combinations and mouse buttons (`Mouse4`, `Mouse5`, …); on Wayland via the GlobalShortcuts portal or compositor bindings
- **CLI** for scripts, status bars (Waybar, …), and Wayland hotkey bindings, with stable exit codes and versioned JSON output
- **Favorites** as YAML files in a folder: hand-written (compact notation) and generated by scripts (explicit notation), with color and icon inherited down the hierarchy, and live reload
- **Offline buffer**: entries are queued locally (SQLite) while aw-server is unreachable and sent in order later
- **Hardware devices** (off by default): timeBuzzer via USB MIDI on Linux, selected by `aw-manual devices list` instead of built-in IDs, extensible with further drivers
- **Notifications**: idle reminder within working hours, long-running activity, resume after a restart, offline buffering
- **Settings window** that edits the same YAML files and keeps your comments
- Linux (GNOME, KDE Plasma, Hyprland, …), macOS, and Windows

## Installation

| Platform | Package |
|---|---|
| Debian / Ubuntu | `aw-manual_<version>_amd64.deb` (`sudo apt install ./aw-manual_*.deb`) |
| NixOS / Nix | flake: `github:arstulke/aw-manual` (package, NixOS module, Home Manager module) |
| macOS | `aw-manual_<version>_universal.dmg` |
| Windows | `aw-manual_<version>_x64_en-US.msi` or `aw-manual_<version>_x64-setup.exe` |

Packages are built by CI ([workflow](.github/workflows/ci.yml)) and attached to
[GitHub releases](https://github.com/arstulke/aw-manual/releases). Each package contains the desktop daemon `aw-manual-daemon` and
the CLI `aw-manual`:

- **deb**: both are installed to `/usr/bin`.
- **Windows**: the installers add the installation folder to `PATH`.
- **macOS**: link the CLI into your `PATH` once:
  `sudo ln -s /Applications/aw-manual.app/Contents/MacOS/aw-manual /usr/local/bin/aw-manual`

aw-manual needs a running [aw-server](https://docs.activitywatch.net/) (local by
default, `http://localhost:5600`; a remote server works too).

### Nix

```nix
# flake.nix
{
  inputs.aw-manual.url = "github:arstulke/aw-manual";

  outputs = { nixpkgs, home-manager, aw-manual, ... }: {
    # NixOS: installs aw-manual and starts the daemon with the graphical session
    nixosConfigurations.my-host = nixpkgs.lib.nixosSystem {
      modules = [
        aw-manual.nixosModules.default
        { programs.aw-manual.enable = true; }
      ];
    };

    # or Home Manager
    homeConfigurations.me = home-manager.lib.homeManagerConfiguration {
      modules = [
        aw-manual.homeManagerModules.default
        {
          services.aw-manual = {
            enable = true;
            # optional: manage config.yaml with Nix (the settings window can't change it then)
            settings.hotkeys.popover = "Mouse4";
            # optional: favorites files (explicit notation keeps the order)
            favorites."50-nix".favorites = [
              { id = "acme"; title = "ACME"; color = "#E4572E"; children = [
                { id = "dev"; title = "Development"; }
              ]; }
            ];
          };
        }
      ];
    };
  };
}
```

`nix run github:arstulke/aw-manual#default` starts the CLI; the daemon is
`aw-manual-daemon`.

### From source

Requirements: Rust (stable), Node.js 20+, and on Linux the WebKitGTK and
AppIndicator development packages
(`libwebkit2gtk-4.1-dev libayatana-appindicator3-dev librsvg2-dev libssl-dev` on Debian/Ubuntu).

```sh
(cd ui && npm ci && npm run build)        # the UI is embedded into the daemon
cargo build --release -p aw-manual-cli -p aw-manual-daemon
# binaries: target/release/aw-manual and target/release/aw-manual-daemon
```

Installers: `node scripts/prepare-sidecar.mjs` builds the CLI for bundling, then
`cd crates/daemon && ../../ui/node_modules/.bin/tauri build --config tauri.release.conf.json`.

## Quick start

1. Start the daemon: `aw-manual-daemon` (or from your application menu). On
   the first start it creates the configuration folder with a commented
   `config.yaml` and opens the settings window.
2. Add favorites, either in the settings window or as a file, e.g.
   `~/.config/aw-manual/favorites.d/10-clients.yaml`:

   ```yaml
   favorites:
     ACME:
       _color: "#E4572E"            # applies to ACME and everything below it
       _icon: briefcase
       Website:
         Development:
           _icon: code
         Code Review:
     Break:
       _kind: status
       _icon: coffee
   ```

3. Press **Ctrl+Alt+Space**, type `dev`, press **Enter**. Development is now
   running and is written to the bucket `aw-manual_<hostname>`.

The CLI works the same way:

```sh
aw-manual start acme/website/development --note "Navigation refactoring"
aw-manual status
aw-manual log acme/website/code-review --last 30m
aw-manual stop
```
